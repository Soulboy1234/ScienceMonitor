# User Journey

## 目标用户

- 需要持续追踪空间物理文献的研究人员
- 需要快速扫期刊、找重点、做笔记的学生和博士后
- 想把文献监控接入个人知识管理系统的用户

## 理想体验

1. 配好期刊源和分析后端
2. 每天或每周运行一次
3. 先读周报判断热点
4. 再点开单篇卡片细看
5. 最后把重要文献继续整理进自己的研究笔记

## 可能的流失点

- 抓取不全，用户不信任结果
- 标签太散，后续无法统计
- 总结太模板化，可读性差
- 输出目录混乱，难以长期维护
- 外部 API 配置麻烦，独立部署成本高

## 后续关注指标

- 周报实际被打开和使用的频率
- 单篇卡片是否被继续人工补充
- 用户是否信任“没有漏抓”
- 哪些期刊和主题最常被优先细读
