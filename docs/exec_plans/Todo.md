# Todo

这个文件记录“已经明确、但暂不立项”的近期待办。以后每次发现“要做但本轮不做”的事项，都先加入这里；事项完成后及时移除或改成完成说明。

使用原则：

- `active/`：已经正式开工的阶段计划
- `completed/`：已经完成的阶段计划
- `Todo.md`：近期明确排队项
- `tech_debt_tracker.md`：长期工程债和方向性问题
- 优先级标记：
  - `P0`：影响主流程正确性或安全性，优先进入 active 计划
  - `P1`：影响产出质量、token 成本或用户操作效率，近期处理
  - `P2`：体验优化、迁移整理或长期增强，排队处理
