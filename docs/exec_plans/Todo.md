# Todo

这个文件记录“已经明确、但暂不立项”的近期待办。

使用原则：

- `active/`：已经正式开工的阶段计划
- `completed/`：已经完成的阶段计划
- `Todo.md`：近期明确排队项
- `tech_debt_tracker.md`：长期工程债和方向性问题
