# 计划：2026-04-17_标签否定语义修复计划

## 目的 / 大图景
- 修复文章总结标签审核中“标签在前、否定语义在后”时未能正确去除 formal 标签的问题。
- 当前已确认的误判样例是 `Ghosh 2026 - JGR.SP - 2024年母亲节超级磁暴期间中高纬电离层扰动的VLF与SABER联合观测` 被错误打上 `对象/热层/密度` 与 `应用/卫星影响`。

## 背景与定位
- 现有 `should_keep_formal_tag()` 已支持“未涉及热层密度”这类前置否定。
- 但对“与热层密度的直接联系未展开”“对卫星环境的定量影响不能外推”这类后置否定句式拦截不足。
- 这会导致正文已经明确排除的标签仍然保留在最终输出中，并进一步污染周报推荐论文标签。

## 工作范围
- `src/sciencemonitor/tag_review.py`
- 相关测试
- `auto/article_summaries`
- `research_reports/2026-04-17 周报.md`

## 非目标
- 不重构整套标签治理体系
- 不改 `manual` 输出
- 不在这一步扩 formal 标签树

- [x] 步骤 2：补充回归测试，覆盖 Ghosh 类样例
- [x] 步骤 3：重审 auto 输出并清理误判标签
- [x] 步骤 4：重建 2026-04-17 周报并验收

## 计划中的工作
- 修复 formal 标签保留条件中的后置否定语义漏洞。
- 清理 `auto` 中已经被误打的 `对象/热层/密度` 与 `应用/卫星影响`。
- 重建 `2026-04-17` 周报，确保推荐论文与主题推荐不再继承这些误判。

## 具体步骤
1. 扩展 `tag_review.py` 中热层密度与卫星影响的 negation patterns。
2. 补充回归测试，覆盖 “与热层密度的直接联系未展开” 与 “不能进一步外推到卫星或应用影响” 这两类句式。
3. 运行 `reconcile_auto_output_tags_with_review()` 重审已有 `auto` 输出。
4. 重建 `2026-04-17` 周报并执行 harness 验收。

## 发现与意外
- 这次误判不是正文真的提供了错误证据，而是补充说明中的否定语义写在标签词后面，现有规则只覆盖了前置否定。
- `应用/卫星影响` 也存在同类漏洞，尤其是在“不能外推到应用影响”这种表达下。

## 决策记录
- 否定语义优先于关键词命中。
- 对摘要级总结，只要补充说明明确写出“不涉及/未展开/不能外推”，就不保留相应 formal 标签。

## 结果与复盘
- 已修复 `对象/热层/密度` 与 `应用/卫星影响` 在“标签词在前、否定语义在后”场景下的误判。
- 已补充“不能进一步外推”“不涉及”“未展开”一类后置否定规则，并覆盖 Ghosh、Hanley、Neupane 这类摘要级总结。
- 已修复单篇总结复用链路：复用已有 Markdown 时，优先以磁盘当前内容为 source of truth，不再把数据库中的旧标签重新并回。
- 已提升周报分析缓存版本，并把单篇标签/正文摘要纳入缓存签名，避免周报继续复用旧标签分析结果。
- `auto` 已重审并通过 `tag_output_review`；`2026-04-17 周报` 已重建，推荐论文中的 Ghosh 条目已不再误挂热层密度或卫星影响。
