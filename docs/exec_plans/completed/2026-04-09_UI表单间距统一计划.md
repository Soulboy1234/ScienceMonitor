# 计划：2026-04-09_UI表单间距统一

## 目的 / 大图景
- 统一周报、深度解读、人工中转、设置页任务面板内各参数项的垂直和水平节奏。
- 把“表单项间距一致性”补进 UI harness，避免只看大布局而忽略微观排版质量。

## 背景与定位
- 当前任务面板的参数项来自 `row`、`checks`、`field-shell`、`actions` 多层容器叠加，间距来源不统一。
- 用户在周报页看到“报告日期 / 统计窗口 / 先更新再生成”等字段之间的间距明显不一致，其他页面也有同类问题。
- 这类问题不属于业务逻辑错误，但会直接影响界面可读性和操作体验，应纳入 harness 的 UI 质量要求。

## 计划中的工作
- 先把表单容器改成统一的纵向节奏模型，再收敛字段卡片和 checkbox 卡片的间距。
- 完成后至少跑 `pytest tests/test_config_ui.py tests/test_config_ui_review.py tests/test_config_ui_visual_review.py -q`、`harness-check` 和 `git diff --check`。

## 具体步骤
1. 为任务面板增加统一的表单堆叠容器和 spacing 变量。
2. 去掉 `field-shell`、`checks`、`actions` 之间重复叠加的 margin。
3. 在周报、深读、人工中转、设置页套用统一布局。
4. 在视觉检查中增加对周报任务面板连续字段垂直间距一致性的断言。
5. 跑校验并归档计划。

## 发现与意外
- 之前的 UI 视觉检查主要覆盖了“卡片是否同一行、是否横向溢出”，没有覆盖“字段级纵向节奏是否均匀”。
- 真正导致用户截图里间距失衡的，不是单一 CSS 值，而是 `field-shell.margin-bottom + checks.gap + actions.margin-top + input[type=file].margin-bottom` 的叠加。

## 决策记录
- 不继续做零散的单卡片微调，而是统一引入 `form-stack` 作为任务面板内部的唯一纵向节奏层。
- `field-shell`、`checks`、`actions`、文件上传控件统一去除额外外边距，避免多层叠加。
- 在 `config_ui_review` 中要求 `form-stack` 和关键 CSS 片段存在，在 `config_ui_visual_review` 中增加周报表单间距方差检查。

## 结果与复盘
- 周报、深度解读、人工中转、设置页都切换到了统一的 `form-stack` 结构。
- 视觉检查现在不仅能发现“大布局错位”，也能发现任务面板字段级纵向间距异常。
- 这一类问题以后如果再次出现，优先检查是否绕过了 `form-stack`，而不是继续在单个字段上打补丁。
