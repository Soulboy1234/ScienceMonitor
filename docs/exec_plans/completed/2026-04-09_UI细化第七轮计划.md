# 计划：2026-04-09_UI细化第七轮

## 目的 / 大图景
- 继续把 `config-ui` 收口成稳定、可读、可操作的本地控制面。
- 收紧 tooltip 的说明质量，让字段解释真正承担“变量定义 + 作用 + 调整影响”的职责。
- 保证这轮 UI 细化仍然进入 harness 的计划、测试和校验链路。

## 背景与定位
- 当前 UI 的结构已经基本稳定，但周报页左右比例、设置页分析后端说明和全局 tooltip 解释仍不够清楚。
- 用户明确要求：周报参数区更宽、监测期刊区更窄；分析后端的说明要聚焦“是什么、干什么、调了会怎样”；并整体优化所有 hover 浮窗内容。
- 本轮不新增新模块，重点是说明质量和局部布局收口。

## 具体步骤
1. 调整周报页面面板宽度比例，把参数区放宽，期刊区缩窄。
2. 删除分析后端卡片下方的多余说明，并重写“分析后端”等关键字段 tooltip。
3. 统一重写各页主要字段的 hover 说明，明确字段定义、作用和影响。
4. 更新 UI 测试和必要的审查规则。
5. 跑校验并归档计划。

## 发现与意外
- 真正影响可理解性的不是 tooltip 数量，而是原来的文案只说明“怎么填”，没有说明“这个变量在程序里的角色”和“改动后会造成什么结果”。
- 周报页右侧期刊面板的空白问题，本质上不是数据缺失，而是宽度和阅读密度不匹配；缩窄右栏后，卡片信息密度反而更合理。

## 决策记录
- 周报页保持首行双面板，但比例从 `1:1` 改为 `3:1`，优先给参数区足够宽度。
- `分析后端` 下方的静态说明删除，只保留问号浮窗解释，避免同一信息重复出现。
- tooltip 文案统一采用“这个字段是什么 / 干什么 / 调整后会怎样”的口径，不再使用过短的提示句。

## 结果与复盘
- 周报页参数区已放宽，监测期刊区改为窄栏滚动展示。
- 设置页 `分析后端` 的解释已改成字段级 tooltip，下方冗余说明已移除。
- 周报、深度解读、人工中转、设置页的主要 hover 浮窗已统一成更完整的解释口径。
- `tests/test_config_ui.py` 与 `config_ui_review` 仍保持通过，说明这轮修改已进入 harness 审查链路。
