# 计划：2026-04-14_pending标签人工审阅执行

## 目的 / 大图景
- 把 `config/tag/pending_tags.md` 中人工编辑的标签审阅结果真正落到输出文件、预选标签和正式标签体系。
- 让“删除 / 备注 / 勾选转正”从一次性人工说明变成可执行、可复查的治理流程。

## 背景与定位
- 用户已在 `pending_tags.md` 中人工补充父类、备注和删除指令。
- 当前程序还不能理解这类人工备注，也不能把“转正后 formal Markdown 显示 `【AI总结】`、但 JSON 不带尾缀”的规则稳定落地。

## 工作范围
- `config/tag/pending_tags.md`
- `config/tag/formal_tags.md`
- `config/focus_tags.json`
- `src/sciencemonitor/tag_governance.py`
- 相关测试
- `output_root()/auto` 下真实输出文件

## 非目标
- 本轮不修改 `manual/` 输出。
- 本轮不重写文章正文，只处理标签行和必要的文件删除。
- 本轮不扩展大规模 formal taxonomy，只根据用户在 `pending_tags.md` 中的指令执行。

## 进度
- [x] 步骤 1：解析 `pending_tags.md` 中的人工编辑、备注和勾选状态。
- [x] 步骤 2：把删除与重命名指令落到 `auto` 输出文件。
- [x] 步骤 3：按备注优化对应标签，并刷新 pending。
- [x] 步骤 4：把勾选条目转正到 formal，并在 Markdown 中加 `【AI总结】` 尾缀。
- [x] 步骤 5：验证结果并归档计划。

## 计划中的工作
- 给 pending 审阅引入“人工指令解析”能力，支持 `-删除` 和自由备注。
- 对被备注的 tag，优先做安全替换；对被标记删除的 tag，直接删除对应输出文件。
- 刷新 pending 后，再把当前这批确认通过的 tag 转正到 formal。
- 保持 `formal_tags.md` 显示 `【AI总结】`，但同步到 `focus_tags.json` 时自动去掉尾缀。

## 具体步骤
1. 解析 `pending_tags.md`，识别每条记录的当前标签、勾选状态、次数和备注。
2. 以当前 `pending_tags.json` 的排序结果为基准，对应回原始待审 tag，生成“旧 tag -> 新 tag / 删除 / 备注”的动作列表。
3. 修改 `auto/article_summaries` 与 `auto/deep_reads` 中的标签；对 `-删除` 的条目删除相关文件。
4. 刷新 `pending_tags.json` 与 `pending_tags.md`。
5. 将当前确认转正的目标 tag 写入 `formal_tags.md`，显示 `【AI总结】` 尾缀，并同步 `focus_tags.json`。
6. 跑定向测试与 tag governance 检查，最后归档计划。

## 发现与意外
- `pending_tags.md` 的人工备注会破坏旧的 checkbox 解析器，导致此前刷新 pending 时无法稳定保留勾选状态。
- `pending_tags.md` 中同一分类下多个条目次数相同且用户手改标签时，不能只靠位置配对；需要先用“未改项精确匹配 + 父类/叶子相关性匹配”锁定原始 tag。
- `formal_tags.md` 当前以 2 空格为主表示层级，旧的缩进深度函数会把部分 4 空格子项读浅一层，已在本轮修正。

## 决策记录
- 把 pending Markdown 的人工编辑视为一次“审阅指令集”，正式流程变为：解析备注 -> 改输出文件/删文件 -> 刷新 pending -> 转正式。
- `-删除` 直接删除对应 `auto` 输出文件；其他备注优先解析成明确目标 tag。
- formal Markdown 显示 `【AI总结】`，但同步到 `focus_tags.json` 时自动去掉尾缀，避免污染机器资产。

## 结果与复盘
- 已执行本轮 pending 人工审阅动作，删除 `auto` 输出文件 41 个，改写标签文件 36 个。

- 已把 `formal_tags.md` 与 `focus_tags.json` 的同步逻辑改为兼容 `【AI总结】` 尾缀显示；Markdown 保留显示，JSON 只保留 canonical label。
- 当前标签治理检查通过；整体验证若失败，仅剩仓库中既有的 `golden article_summary drift`，与本轮标签审阅流程无关。
