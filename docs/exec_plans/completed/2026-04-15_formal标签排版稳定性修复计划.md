# 计划：2026-04-15_formal标签排版稳定性修复

## 目的 / 大图景
- 修复 `formal_tags.md` 在标签转正或合并时被默认渲染器整页重写、导致人工整理版式丢失的问题。
- 让 formal 的人工 source of truth 真正稳定，后续新增标签时尽量保留当前排版与顺序。

## 背景与定位
- 当前 `merge_tags_into_formal()` 会读取 `focus_tags.json` 后重新渲染 `formal_tags.md`。
- 这会把用户手工整理的顺序和缩进样式冲掉，表现为 formal 排版“又变奇怪了”。
- `formal_tags.md` 仍应是人工 source of truth，新增标签不应反向由 JSON 驱动版式。

- `src/sciencemonitor/tag_governance.py`

- 视需要补充 formal 渲染相关测试

- 不处理 pending 或 auto 标签语义问题
