# 计划：2026-04-30_UI深度解读元数据与Tag质量修复

## 目的 / 大图景
- 修复 UI 上传 PDF 触发深度解读时的元数据误判，避免 PDF 是一篇论文、输出引用却变成另一篇论文。
- 继续优化 Ollama 深度解读输出的 tag 根类、占位文本和“与已有工作关系”段落质量。
- 保持 Codex 深度解读正文逻辑不被顺手改动；通用 tag 后处理可共享，正文生成逻辑只做质量审计和格式修复。

## 背景与定位
- 本次 UI 运行记录在 `log/deep_read_ui_observation/20260430_061732/summary.md`。
- 用户上传 PDF：`JGR.SP - Aryan (2023) A Statistical Analysis of the Auroral Streamer Current System.pdf`。
- 运行阶段为 `ollama_evidence -> ollama_final -> ollama_revision -> done`，耗时 254.4 秒。
- 输出 Markdown 却变成 Donaldson 2011 的 Eos 论文，根因是 UI 从文件名推断标题时把 `JGR.SP - Aryan ...` 二次 `Path(...).stem` 截断成 `JGR`，随后弱标题触发 Crossref title lookup。
- 生成报告还暴露了 tag 根类错误：`SECS技术` 被放进 `对象/`，`Streamers` 被放进 `仪器/`。
- Ollama 输出中也出现了“未提取到明确条目”占位，以及“与已有工作的关系”只剩关系等级的弱文本。

## 计划中的工作
- 去掉上传 PDF 文件名推断中的第二次 `Path(...).stem`。
- 从 explicit PDF metadata 中读取 DOI/Title，并让 PDF DOI 优先于弱文件名标题。
- 禁止 `JGR`、`GRL` 等弱标题触发 Crossref title lookup。
- 将 `Streamers/auroral streamers` 归一到 `对象/极区/极光/流光`，将 `SECS技术` 归一到 `方法/SECS`。
- 清除深读关键结果中的“未提取到明确条目”占位，并扩展裸关系等级文本。

## 具体步骤
1. 修复 `_uploaded_pdf_title()`，确保 `JGR.SP - Aryan ...` 保留完整 stem。
2. 在 `_resolve_metadata()` 中读取 explicit PDF metadata，优先使用 PDF DOI 查询 Crossref。
3. 增加弱标题判断，弱标题不做本地库或 Crossref title lookup。
4. 扩充正式标签和机器标签资产，补齐 `对象/极区/极光/流光`、`方法/SECS` 及 Chen 相关 Dst/Kp 别名。
5. 在深读 Markdown 后处理中过滤占位关键结果，并把裸关系标签扩展为待复核说明。
6. 用 deep-read tag reconcile 只改写 `auto/deep_reads` 下旧输出的 tag 行。
7. 更新 golden deep_read，反映占位条目被删除后的预期输出。

## 发现与意外
- PDF metadata 中包含正确 DOI `10.1029/2023ja031686` 和标题 `A Statistical Analysis of the Auroral Streamer Current System`，可以可靠覆盖弱文件名标题。
- `sync_formal_tags_to_focus_tags_json()` 会重写机器资产，需要补回 Dst/Kp、SNMC、统计/特征等人工维护 alias/pattern。
- `tag_output_review` 扫描到旧的 Donaldson/Aryan 误生成文件 tag 行仍未与新审核器一致，因此需要执行深读输出 tag reconcile。
- golden drift 只来自删除“未提取到明确条目”占位，属于本轮预期行为变化。

## 决策记录
- 对 provided PDF，PDF 内嵌 DOI/Title 的可信度高于文件名；文件名高于用户未确认的短标题。
- 短标题、期刊缩写和过短大写串不得自动触发 Crossref title lookup。
- `SECS` 是方法，不是研究对象；`Streamers/auroral streamers` 是极光流光对象，不是仪器。
- 旧输出只改 tag 行，不动正文、引用和用户手动对比文件内容。

## 结果与复盘
- UI 上传 PDF 标题不会再被 `JGR.SP` 中的点号截断。
- explicit PDF DOI/Title 会在深度解读元数据解析中优先生效，并阻止弱标题误命中 Crossref。
- 深读 tag 审核可补回 `对象/极区/极光/流光` 和 `方法/SECS`，并避免 `仪器/Streamers`、`对象/SECS技术`。
- 深读 Markdown 后处理会删除关键结果占位条目，并避免关系段只输出“直接相关”等裸标签。
- 已重写旧深读输出的 tag 行，单篇总结输出未被扫描或重写。
