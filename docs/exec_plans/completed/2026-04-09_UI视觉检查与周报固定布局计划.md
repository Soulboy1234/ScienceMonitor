# 计划：2026-04-09_UI视觉检查与周报固定布局

## 目的 / 大图景
- 为 UI 增加真实浏览器渲染级的视觉检查，弥补当前 harness 只看结构、不看最终布局的问题。
- 修复周报页首行面板在半屏模式下自动换行的行为，保持固定布局。

## 背景与定位
- 最近周报页出现了“结构检查通过，但实际浏览器中布局崩坏”的问题，说明当前 UI harness 缺少渲染级护栏。
- 用户明确要求周报页的“周报生成参数 / 当前监测期刊”保持固定 `3:1` 布局，不随浏览器窗口缩窄而自动拆成两行。

## 工作范围
- `scripts/requirements/requirements-local.txt`
- `.github/workflows/ci.yml`
- `scripts/bootstrap_local_env.sh`
- `src/sciencemonitor/ui_assets/config_ui.css`
- `src/sciencemonitor/config_ui_visual_review.py`
- `src/sciencemonitor/harness.py`
- `tests/test_harness.py`
- `tests/test_config_ui_visual_review.py`

## 非目标
- 不做整站像素级截图比对。
- 不重做 UI 信息架构。
- 不修改周报业务逻辑。

## 进度
- [x] 固定周报页首行布局，不再随窗口宽度自动拆行。
- [x] 增加浏览器渲染级 UI 视觉检查，并接入 harness。
- [x] 补齐依赖、测试和 CI 支撑。
- [x] 回填并归档计划。

## 计划中的工作
- 先修周报页 CSS，再增加浏览器渲染级 visual review。
- visual review 采用“真实浏览器打开样例页面 + 布局断言 + 截图留档”的方式，不做脆弱的全像素 diff。

## 具体步骤
1. 移除周报页会把首行两块面板堆叠成两行的断点规则。
2. 增加 `config_ui_visual_review`，在固定视口下检查无横向溢出、周报页首行卡片同列且宽度比接近 `3:1`。
3. 在 visual review 中保存截图到 `log/ui_visual_review/` 作为审计产物。
4. 接入 `harness-check`，并补依赖、测试和 CI。
5. 跑校验并归档计划。

## 发现与意外
- “周报页在半屏下换成两行”并不是断点策略本身失效，而是之前缺失的 `.span-9` / `.span-3` 栅格类和后续的堆叠断点叠加造成的实际布局漂移。
- 在把 `config_ui_visual_review` 接入 `HarnessCheckReport` 后，维护测试里的假 harness 报告也需要同步补字段，否则全量测试会失败。

## 决策记录
- 不做整站像素级截图对比，改为“固定视口真实浏览器渲染 + 布局断言 + 截图留档”的视觉检查。
- 周报页首行面板恢复固定 `3:1` 布局，不再因为浏览器窗口缩窄自动拆成两行；仅保留字段区在更窄宽度下改单列。
- 把 Playwright Chromium 纳入本地 bootstrap 和 CI，确保视觉检查不是只在开发机上可用。

## 结果与复盘
- `harness-check` 现在除了结构检查，还会执行一轮真实浏览器 UI 视觉检查，并把截图输出到 `log/ui_visual_review/`。
- 周报页在 `960px` 视口下会保持首行同排，宽度比由视觉检查断言，避免再次出现“用户看到坏页面，但 harness 仍然通过”的情况。
- 这轮之后，UI harness 进入“结构检查 + 样式检查 + 浏览器渲染检查”三层护栏。
