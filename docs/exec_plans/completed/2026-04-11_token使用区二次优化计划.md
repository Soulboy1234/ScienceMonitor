# 计划：2026-04-11_token使用区二次优化

## 目的 / 大图景
- 优化总览页 token 使用区的表达方式，让“总量 + 调用次数”更清楚，图表坐标更接近常见统计图习惯。
- 把这次 UI 调整纳入 visual review，避免样式回退。

## 背景与定位
- 当前 token 摘要只显示今天 / 本周 / 本月的 token 总量，没有同时显示调用次数。
- 图表上方的“30 天”标记无必要，横坐标日期也还没有完全落到坐标轴下方。
- 纵轴刻度现在直接取原始比例，用户希望尽量取成 `xxx,000` 这种更好读的整数级别。

## 工作范围
- `src/sciencemonitor/token_monitor.py`
- `src/sciencemonitor/config_ui_page_sections.py`
- `src/sciencemonitor/ui_assets/config_ui.css`
- `src/sciencemonitor/config_ui_review.py`
- `src/sciencemonitor/config_ui_visual_review.py`
- `tests/test_config_ui.py`

## 非目标
- 本轮不修改其他页面。
- 本轮不改变 token 日志来源和持久化格式，只调整展示与刻度生成。

- [x] 步骤 2：优化图表 DOM / CSS，移除 30 天标记并调整横轴日期位置。
- [x] 步骤 3：补测试、视觉检查并重启面板。

## 计划中的工作
- 先改数据层摘要与刻度。
- 再改总览页 token 图结构与样式。
- 最后跑验证并重启 config-ui。

## 具体步骤
1. 让今天 / 本周 / 本月同时显示 token 和调用次数。
2. 让纵轴刻度尽量落在整千位。
3. 去掉图上方 30 天标记，并把日期标签明确放到横轴下方。
4. 更新 review / visual review / 测试。
5. 重启 config-ui。

## 发现与意外
- token 图的默认文案入口不只在 `token_monitor.py`，`config_ui.py` 和 `config_ui_state_summary.py` 也有兜底字符串，需要一起更新，否则 UI 在无数据或旧缓存路径下会退回旧格式。
- 仅改 CSS 不足以满足“日期在横轴下方”，必须把日期标签从每根 bar 内部移到独立的横轴标签网格里。

## 决策记录
- 保留 30 天窗口，但不再在图上额外显示“30 天”椭圆标记，避免和柱状图主体争夺注意力。
- 纵轴不再按固定 25% 比例取值，改为使用整千优先的 nice step，保证刻度更接近 `xxx,000` 这类可读整数。
- 横轴日期只显示首尾和每 7 天一个锚点，但所有 30 天仍保留对应的对齐网格，保证视觉稳定。

## 结果与复盘
- 今天 / 本周 / 本月摘要已改成“token 数 + 调用次数”形式。
- token 图已去掉顶部椭圆标记，横轴日期已移动到坐标轴下方。
- 视觉检查已覆盖总览页 token 图，避免再次出现“测试通过但用户看不到目标效果”的情况。
