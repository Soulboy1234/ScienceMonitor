# 计划：2026-04-29_深度解读Tag补全修复

## 目的 / 大图景
- 修复深度解读既有输出重写后 tag 过少的问题。
- 让 deep-read-only tag 审计/重写不仅清除错误 tag，也能从深读正文和中间 cache 可见证据补回核心 tag。
- Chen 2025 GRL 样例不应只剩 `磁暴 + Dst + Kp`，还应覆盖地震、日地耦合、SNMC、统计/时滞相关等关键检索维度。

## 背景与定位
- Chen final cache 原始 tags 包含 `地磁暴、地震、D指数、K指数、SNMC算法`。
- 上一轮重写只审计当前输出首行 tag，无法补回旧输出中已经缺失的 `地震`、`SNMC算法`。
- 现有 formal tag 缺少 `事件/地震`、`方法/SNMC`、`特征/时滞相关` 等交叉论文所需的稳定 tag。

## 发现与意外
- Chen 顶行先前只剩 3 个 tag 的直接原因是重写流程只清洗已有首行 tag，没有从正文补回 `事件/地震`、`方法/SNMC` 等已经缺失的标签。
- 真实 Chen 正文的后续问题提到“月球潮汐力”，旧的 `对象/日地耦合` 证据门槛把任何非地球行星词都作为排除项，导致题名明确的“太阳-地球相互作用”也被压掉。

## 决策记录
- tag 补全只在 deep-read context 生效，不影响单篇总结。
- 机制类内容不放 `对象/`，只对明确、稳定、正文直接讨论的机制使用 `特征/`。
- 明确的 `solar-terrestrial / 太阳-地球相互作用` 证据优先于正文中次要出现的月球/其他行星词，避免追踪问题或参考背景误删主线 tag。
