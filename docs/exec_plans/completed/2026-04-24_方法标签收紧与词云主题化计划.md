# 计划：2026-04-24_方法标签收紧与词云主题化

## 目的 / 大图景
- 收紧当前标签体系中过宽、无区分度的方法类标签，避免它们污染文章总结与周报主题分布。
- 修复 `Hanley` / `Neupane` 两篇文章在周报重建后反复回写旧 alias 的问题。
- 把周报词云图改成真正服务于“科学主题分布”的视图，而不是把方法类和低频标签堆成难读列表。

## 背景与定位
- 当前 `方法/数据分析` 已进入正式标签，但覆盖过宽，导致大量不同研究被无差别贴上同类标签。
- `Hanley` / `Neupane` 两篇文章曾多次在周报重建后重新出现 `#其他行星/火星` / `#其他行星/土星` 旧 alias，需要定位根因而不是继续手工补丁。
- 现有词云图虽然统计上覆盖了全部非管理标签，但主图过小、低频标签堆入底部列表，无法承担“快速读出本周科学主题”的作用。

## 非目标
- 不在这轮大改 formal 其他方法类标签。
- 不处理 UI 改动。
- 不调整周报正文其他章节的结构。

## 计划中的工作
- 先收紧正式标签与生成映射，停止继续产出 `方法/数据分析`。
- 再复现实验，确认旧 alias 是在哪条重建链路里回写，并加回归测试。
- 最后修改词云图过滤与排版，让低频科学主题进入主图，去掉底部列表。

## 具体步骤
1. 修改 formal 标签与同步逻辑，确保 `focus_tags.json` 不再保留 `方法/数据分析`。
2. 调整 tag 审核和 pending 归并，避免把宽泛方法词再次吸收到 formal。
3. 复现 `Hanley` / `Neupane` 的再生成过程并补测试，再修复根因。
4. 修改词云图过滤规则，排除管理标签和泛方法标签，并把所有保留标签放入单个主图。
5. 重建 2026-04-17 周报，检查真实词云图与相关 `auto` 文件。
6. 跑测试、`golden-eval`、`harness-check`，通过后归档计划。

## 发现与意外
- `Hanley` / `Neupane` 的旧 alias 不是单篇总结生成链路写回，而是 `sync_out_library()` 中的 `normalize_other_planet_tag()` 仍按旧规范 `其他行星/*` 回写。
- 词云图显示不清的直接原因不是“没有统计到低频标签”，而是主图尺寸与字体缩放比例失衡，低频标签虽然进入统计但在旧布局中几乎不可读。

## 决策记录
- 词云图优先服务于“科学主题分布”，因此本轮允许过滤掉方法类泛标签，即使它们在原始标签统计中存在。

## 结果与复盘
- `方法/数据分析` 已从正式标签中移除，并在审核与治理层中加入阻断，避免再次进入 formal、pending 或输出文件。
- `sync_out_library()` 的行星标签规范已切换到 formal 风格 `对象/其他行星/*`，完整周报重建后 `Hanley` / `Neupane` 不再回写旧 alias。
- 周报词云图改为单主图排版，去掉底部“其余标签”列表，排除 `信息来源/*` 与 `方法/*`，并保留全部非管理标签。
- 以 2026-04-17 周报为例，本次共纳入 32 篇文章、72 个非管理标签，词云显示标签数 72，未遗漏标签 0，其中低频单次标签 61 个。
