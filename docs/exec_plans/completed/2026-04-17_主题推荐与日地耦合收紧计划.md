# 计划：2026-04-17_主题推荐与日地耦合收紧

## 目的 / 大图景
- 收紧周报“主题推荐”的主题抽象标准，只保留研究对象或科学问题，避免把“数据分析”“统计研究”“日地耦合”这类过泛概括当作主题。
- 收紧 `对象/日地耦合` 的保留条件，只有在论文真实涉及从太阳到地球、跨多圈层耦合链条时才允许保留。
- 同步修复文章总结标签审核、周报主题聚类和周报输出，使 2026-04-17 周报能反映新规则。

## 背景与定位
- 当前周报主题推荐仍会把方法型或过泛过程型标签提升为主题，削弱分类意义。
- 当前 `对象/日地耦合` 在部分局部过程研究中被误保留，导致标签泛化。
- 这轮工作只处理周报主题抽象与相关标签治理，不扩展 formal 标签体系。

## 发现与意外
- `对象/日地耦合` 的初版规则会被“明确说本文不讨论跨圈层耦合”的否定句反向触发，因此补了一层专门的否定模式。
- 在现有 `auto` 输出的重审过程中，审核器原先会把 Markdown 顶部旧标签行当作正文证据，导致旧标签自证成立；这轮已改为只使用正文与补充信息取证。
- `日地耦合` 的圈层判定还会被“未直接涉及热层密度/热层风”这类否定补充说明污染，因此把正向证据与否定说明拆开处理。

## 决策记录
- 主题推荐优先服务分类与检索，不承担“方法概括”功能，因此主题候选收口为 `对象` 与 `事件`。
- `对象/日地耦合` 属于高门槛标签，应显式依赖“太阳驱动 + 至少两个地球圈层 + 耦合表述”的组合证据。

## 结果与复盘
- 周报主题推荐已收口到研究对象与事件，不再把 `数据分析`、`统计研究`、`日地耦合` 这类泛概括提升为主题。
- `对象/日地耦合` 已改成高门槛标签：需要显式日地耦合表述，或“太阳驱动 + 至少三个地球圈层 + 耦合表述”的组合证据。
- 已重审 `auto` 输出并重建 2026-04-17 周报；像 Chave 这类局部过程研究中的误打 `对象/日地耦合` 已被清理。
- `harness-check` 已恢复为全通过，golden fixture 已同步到新周报主题逻辑。
