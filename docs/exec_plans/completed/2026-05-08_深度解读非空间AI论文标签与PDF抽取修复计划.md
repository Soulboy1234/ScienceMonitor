# 计划：2026-05-08_深度解读非空间AI论文标签与PDF抽取修复

## 目的 / 大图景
- 修复非空间科学深度解读中的标签误判和正文材料缺漏。
- 让 PINN/XAI 这类相关学科 AI 论文能被正确打上方法标签，同时避免把工程/AI 论文中的 `KP equation` 误识别为空间物理 `Kp` 指数。
- 改善 PDF 全文抽取质量，避免给 Ollama 的深读材料被过度裁剪。

## 背景与定位
- 目标样例是 Naser 2026 `Fundamental flaws of physics-informed neural networks and explainability methods in engineering systems`。
- 当前输出 tag 含 `指数/Kp`，但论文不是空间物理论文；正文中 `KP equation` 是数学方程名，不是 Kp 地磁指数。
- 原始 LLM tag 已给出 `方法/物理信息神经网络` 和 `方法/可解释性人工智能`，但正式词表/归一化没有稳定映射到 canonical，导致 PINN/XAI 没进输出。
- 当前 PDF 抽取使用 `pdftotext -layout` 后再按缩进裁剪；该样例 16 万字符原文被清洗成约 9600 字符，丢失 Kirsch、multiplicative propagation 等关键段落。

## 工作范围
- PDF 文本抽取：`src/sciencemonitor/article_fetch.py`、`src/sciencemonitor/deep_reads.py`、相关测试。
- Tag 词表和审核：`config/tag/formal_tags.md`、`config/focus_tags.json`、`src/sciencemonitor/tag_review.py`、`src/sciencemonitor/tag_governance.py`、相关测试。
- 深读 prompt/质量审计：`src/sciencemonitor/llm_contracts.py`、`src/sciencemonitor/llm.py`、相关测试。
- 只重写自动深读输出 tag 行；不改手工笔记。

## 非目标
- 不把非空间 AI 论文强行纳入空间物理指数/事件标签。
- 不自动把所有 pending tag 转正；只转正本轮明确需要的稳定方法标签。
- 不重写用户手工笔记。

3. 新增/更新正式标签与映射：`方法/建模/机器学习/PINN`、`方法/可解释模型/XAI`，并映射 `物理信息神经网络/PINNs/physics-informed neural networks`、`XAI/可解释性人工智能/explainable artificial intelligence`。
4. 收紧 `指数/Kp`：`KP equation/Kadomtsev-Petviashvili/generalized potential KP` 不触发；非空间论文除非明确 `Kp index/geomagnetic Kp/planetary K index` 才保留。
5. 深读 prompt 与质量审计加入相关学科 AI/工程论文的关键覆盖项，特别是 PINN/XAI 论文需要覆盖核心失败模式、案例、验证建议和适用边界。
6. 用 Naser 样例和单元测试验证。

## 发现与意外
- Naser 样例旧 source cache 来自 `provided_pdf`，但没有 PDF 抽取器版本；旧抽取结果只有 9598 字，且 `Kirsch`、`multiplicative propagation` 等关键段落缺失。
- 同一 PDF 使用 `pdftotext -layout` 的宽松清洗可保留 115018 字，包含 `PINN` 137 次、`XAI` 25 次、`Kirsch` 2 次、`multiplicative` 2 次、`case studies` 8 次。
- 旧最终 cache 原始 tags 含 `方法/物理信息神经网络` 和 `方法/可解释性人工智能`，说明 LLM 已识别主题；真正丢失发生在正式标签映射和 review 之后。
- `指数/Kp` 误入来自 `generalized potential KP equation` 相关工作句子，属于数学方程缩写，不是空间物理 Kp 指数。

## 决策记录
- 相关学科深读允许保留方法类 tag，但不从用户研究偏好反推空间物理指数、仪器或事件 tag。
- `KP equation`、`generalized potential KP` 和中文 `KP 方程` 不再触发 `指数/Kp` 或 article_index 的“空间环境指数”挂接。
- `事件/地震` 需要题名或正文主焦点证据；参考文献或“不是论文主题”的偶然提及不再触发。
- `对象/领域/*` 视为低价值伪对象，不再进入 pending 或输出。

## 结果与复盘
- PDF 抽取改为多候选择优，并给 PDF source cache 写入 `pdf_text_v2` 版本；Naser 样例 source cache 已保留 115018 字，包含案例与建议段。
- Ollama evidence cache 升级为 v3，Ollama quality mode 深读 cache 增加专属签名；Codex 深读 prompt、schema 和 cache variant 未改变。
- 新增 canonical tag：`方法/可解释模型/XAI`；PINN/XAI raw tag 和正文证据可稳定归一到 `方法/建模/机器学习/PINN` 与 `方法/可解释模型/XAI`。
- Naser 新输出顶部 tag 为 `#方法/建模/误差传播 #方法/建模/机器学习/PINN #方法/可解释模型/XAI`，不再含 `#指数/Kp`、`#事件/地震`、`#对象/领域/工程计算`。
- article_index 短英文指数匹配改为 token 边界，并加 KP 方程和业务化否定门槛；Naser 不再挂到“空间环境指数”。
- 深读“和我已有工作的关系”后处理增加重复结尾保护，避免二次审核时重复追加同一条方法论边界说明。
- 自动输出 tag 已重审，pending tag 报告已刷新。
