# 计划：2026-04-09_harness说明收束

## 目的 / 大图景
- 把当前项目里已经成型的 harness 治理内容整理成一份统一说明，避免知识继续散落在 `README`、`AGENTS`、runbook 和对话里。
- 明确区分“harness-check 在检查什么”和“整个 harness 体系还包含哪些相邻 gate”。

## 背景与定位
- 当前项目的 harness 已经覆盖运行检查、计划治理、文档治理、UI 结构/功能/视觉治理、golden eval，以及可选的真实案例 fixture 检查。
- 但这些内容分散在多个文件里，用户问“现在 harness 都监测什么”时，需要手动汇总，说明入口不够清楚。
- 根目录入口文件适合保留短导航，不适合承载完整治理说明。

## 工作范围
- `docs/user_guides/harness_governance_overview.md`
- `README.md`
- `AGENTS.md`
- `docs/README.md`

## 非目标

- 不新增新的 gate。
- 不做版本发布或 GitHub 同步。
