# 计划：2026-04-23_周报推荐理由优化

## 目的 / 大图景
- 优化周报“推荐论文”区块中的推荐理由，使其不再复用单篇总结中的模板化句式，而是更具体地说明“为什么这篇值得看”。
- 保持“各期刊主题汇总”的中文概括现状，不在本轮压缩该部分内容。

## 背景与定位
- 当前周报里的推荐理由基本是“如果你在跟踪 X，这篇文章值得先看摘要、数据来源和方法部分”，信息量低且风格重复。
- 用户要求先优化推荐理由，并明确保留“各期刊主题汇总”的较长中文概括。
- 本轮只调整周报推荐理由生成逻辑，不改周报模板主体，也不改单篇总结正文。

## 工作范围
- `src/sciencemonitor/reporting.py`
- 必要时涉及 `src/sciencemonitor/llm_contracts.py` 或相关测试
- `tests/test_reporting.py`

## 非目标
- 不压缩“各期刊主题汇总”的中文概括
- 不重构单篇总结的 `recommendation` 字段
- 不改 UI
