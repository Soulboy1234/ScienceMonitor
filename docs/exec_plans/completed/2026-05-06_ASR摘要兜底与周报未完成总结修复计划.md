# 计划：2026-05-06_ASR摘要兜底与周报未完成总结修复

## 目的 / 大图景
- 修复最新周报中 ASR 条目长期缺摘要、以及 Ollama 单篇总结结构化输出失败导致周报缺项的问题。
- 目标是让“只找到摘要也好”的条目进入正常单篇总结链路，同时把仍失败的原因在周报中写清楚。

## 背景与定位
- 最新周报显示 6 篇“未完成单篇总结”为 Ollama 结构化 JSON 失败，另 6 篇“未获取摘要/全文”为 ASR 的 Elsevier DOI 条目缺来源材料。
- 本地数据库中这 6 篇 ASR 条目的 abstract 为空；Crossref 也没有摘要，DOI HTML 停在 ScienceDirect/Elsevier 跳转页。
- OpenAlex 对其中部分 DOI 已能提供摘要；ResearchGate 不作为自动抓取来源。

## 工作范围
- 来源材料解析：`src/sciencemonitor/article_fetch.py`。
- 单篇总结失败恢复：`src/sciencemonitor/article_summaries.py` 与必要的 `llm.py` 辅助。
- 周报缺源/失败诊断展示：`src/sciencemonitor/reporting.py`。
- 测试：`tests/test_article_fetch.py`、`tests/test_article_summaries.py`、`tests/test_pipeline.py`、`tests/test_reporting.py`、`tests/test_llm.py`。

## 非目标
- 不自动抓取 ResearchGate 正文。
- 不绕过 ScienceDirect 403 或受限全文。
- 不改变周报推荐排序算法。
- 不用 LLM 给无摘要/无全文条目硬编总结。

## 发现与意外
- 真实 ASR dry run 中，ScienceDirect 跳转 URL 可以从 DOI/Elsevier 跳转页解析出来，但直接请求 ScienceDirect 返回 403，因此只记录诊断和人工链接，不绕过访问限制。
- Semantic Scholar 当前对这些 DOI 返回 429，程序现在记录限流诊断并继续尝试 arXiv。
- 6 篇 ASR 缺源样例中，OpenAlex 自动恢复 3 篇摘要；OpenAlex 提供 arXiv OA URL 的 Aggarwal 2026 通过 arXiv API 恢复摘要；剩余 2 篇仍保留为 `publisher_redirect_only`。

## 决策记录
- 自动来源只使用公开、无需登录的 API/HTML；ResearchGate 只输出人工检索链接。
- 摘要级材料足以生成 `信息来源/仅摘要` 单篇总结。

## 结果与复盘
- `resolve_summary_source_material()` 现在在缺源前尝试 OpenAlex、Semantic Scholar 和 arXiv 摘要；Elsevier/ScienceDirect 跳转页会解析出 PII URL，403 记录为诊断而不是异常。
- 单篇总结的 Ollama invalid structured output 现在会先从原始输出中提取 JSON 并补齐 required 字段；无法修复时再用更短来源文本做一次严格 JSON 重试。
- 周报“其他” section 现在区分 LLM 输出失败和来源材料缺失；缺源条目显示来源诊断和 DOI/ScienceDirect/Google Scholar/ResearchGate 人工检索链接。
- 真实 ASR DOI 验收：6 篇中 4 篇自动恢复摘要，其中 3 篇来自 OpenAlex，1 篇来自 arXiv；剩余 2 篇保留清晰诊断与人工检索入口。
- `tag-candidates --reconcile-output --limit 0` 用于修复 harness 发现的既有自动输出 tag 不一致问题，随后 harness 通过。
