# 计划：2026-04-24_周报词云可读性优化

## 目的 / 大图景
- 提高周报词云图的可读性，让低频标签在图中真正可见，并缩短层级标签显示文本。

## 背景与定位
- 当前词云图已覆盖全部非管理标签，但低频标签大多堆在底部补充区，视觉上难以辨认。
- 当前标签直接显示完整层级路径，例如“对象/磁层/弓激波”，占用空间过大。
- 用户要求低频标签也能看见，并希望显示成更短的末级标签，如“弓激波”。

## 工作范围
- `src/sciencemonitor/reporting.py`
- `tests/test_reporting.py`
- 真实周报输出图片

## 非目标
- 不改周报模板位置
- 不改词云统计口径
- 不改 UI

## 进度
- [x] 步骤 1：确定短标签显示规则与低频标签排版策略
- [x] 步骤 2：实现短标签词云与可读底部补充区，并补测试
- [x] 步骤 3：重建 2026-04-17 周报并运行校验，归档计划

## 计划中的工作
- 先审查当前词云图的布局和标签分布，确认低频标签可见性瓶颈。
- 再把显示文本从完整路径改为短标签，必要时为重名标签保留最小歧义信息。
- 最后重建真实周报并检查图片可读性与 harness 稳定性。

## 具体步骤
1. 设计标签显示名称函数，优先显示末级标签。
2. 对重名末级标签加最小必要前缀，避免完全混淆。
3. 把底部补充区改成更规整、字号更可读的多列列表。
4. 补测试，覆盖短标签显示与全部标签可见性。
5. 重建 2026-04-17 周报并运行 `harness-check`。

## 发现与意外
- 当前词云统计本身已经覆盖全部非管理标签，问题出在视觉布局：低频标签虽然被纳入数据，但由于主云拥挤和底部区过于紧凑，实际图中难以辨认。
- 周报重建后，两个已知历史 alias 标签 `#其他行星/火星`、`#其他行星/土星` 仍会被回写到输出文件，需要在收尾校验前额外清理。

## 决策记录
- 视觉优先级高于纯粹“词云感”；低频标签可读性优先。

## 结果与复盘
- 词云主区域已改成短标签显示，优先显示末级名称，例如 `对象/磁层/弓激波` 显示为 `弓激波`；仅在末级重名时回退到更长后缀。
- 主云未放下的低频标签会进入底部 `其余标签` 多列区，确保本次周报纳入文章中的全部非管理标签都可见。
- 当前真实周报 `2026-04-17 周报` 已重建，词云图已更新；`pytest tests/test_reporting.py -q`、`golden-eval` 和 `harness-check` 已通过。
