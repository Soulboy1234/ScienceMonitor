# 计划：2026-04-17_标签治理收紧与周报标签空格修复计划

## 目的 / 大图景
- 收紧文章总结标签生产逻辑，优先使用正式标签，明显减少无必要的 pending 标签。
- 修复 formal 标签误打问题，尤其是与正文无关的高频标签误判。
- 顺手修复周报“推荐论文”区块里 `标签：` 后缺少空格的问题，保证 Obsidian 能正确识别第一个标签。

## 背景与定位
- 当前标签问题有两类：一类是 formal 标签误打，另一类是 pending 标签过宽、过细、过噪。
- 已确认一条系统性误判链路：规则层只要检测到 `thermosphere` 与 `density/drag` 共现，就直接生成 `对象/热层/密度`，不判断是否为研究主轴。
- 已确认一条治理层放宽链路：未知标签只要字符串合法、未命中 drop 规则，就会进入 pending；当前 pending 中大量标签仅出现 1 次，且很多是时间、地区、组织、参数子项、观测细节等低价值条目。
- 正式标签风格已经较清楚：formal 以稳定、可复用、跨论文复现的对象/事件/指数/仪器/方法层级为主，不鼓励把具体台站、年份、地区、问卷对象、一次性参数组合直接沉淀成 canonical tag。

- [x] 步骤 2：实现新的标签治理规则并修复周报标签空格
- [x] 步骤 3：对现有 auto 输出做必要重审，刷新 pending，并完成 harness 验证

## 计划中的工作
- 先把“什么样的标签值得进入 formal / pending”固化成程序规则，而不是继续靠例外修补。
- 再把高风险 formal 标签做成“有证据才保留”的审核器，优先解决误打。
- 然后收紧 pending 准入，只保留真实有审阅价值的新标签。
- 最后对现有 `auto` 输出重审一轮，让历史输出和新规则重新一致。

## 具体步骤
1. 为高风险 formal 标签建立证据门槛，优先覆盖 `对象/热层/密度`、`对象/热层/风场`、`对象/电离层/TEC`、`对象/电离层/电子密度`、`事件/磁暴`、`事件/亚暴`、`应用/卫星影响` 等易误打项。
2. 收紧规则层推断，避免由补充说明中的否定句、背景句或泛词共现直接生成正式标签。
3. 收紧 pending 准入：低价值、一次性、元信息型、地区/时间/组织/人群/细碎参数类候选标签优先丢弃或压缩到 formal 既有层级，不再直接进入 pending。
4. 修复周报 `推荐论文` 中的 `标签：` 输出格式。
5. 重跑相关测试、标签审计和 `harness-check`，必要时对 `auto` 做标签重审并刷新 pending。

## 发现与意外
- `Li 2026 - SW - 太阳风参数对外辐射带电子通量预测能力评估` 的正文明确写了“不涉及热层密度”，但输出标签仍有 `对象/热层/密度`，说明现有 formal 标签审核器不会主动删除缺乏正文证据的 formal 标签。
- 当前 pending 中真实存在的标签约 190 个，几乎全部是 `1次`；这进一步说明 pending 准入门槛偏低，而不是研究主题真的高度发散。
- 对历史 `auto` 输出做重审时，不能只看标签行本身，否则会被旧标签反向污染；审核器必须至少剔除标签行，并优先依据英文题目、正文段落和补充说明里的否定语句做判断。

## 决策记录
- 这轮优先改“标签生产与审核链路”，而不是先人工清单式清理 pending。
- pending 不再把“只要合法、看起来像层级结构”的未知标签默认收下；必须同时满足更严格的科学内容价值标准。
- formal 误打优先通过审核器删除，而不是试图靠更多 alias 或 pending 规则兜底。

## 结果与复盘
- 已完成 formal 标签证据门槛收紧：`对象/热层/密度`、`对象/热层/风场`、`对象/电离层/TEC`、`对象/电离层/电子密度`、`对象/极区/电子密度`、`事件/磁暴`、`事件/亚暴`、`应用/卫星影响` 现在都会经过正文证据审核。
- 已完成 pending 准入收紧：地区、时间、组织、人群、观测站、多点观测、参数、指标、载荷、介质、驱动等低价值候选默认不再进入 pending；部分可归并项会直接改写到 formal。
- 已对现有 `auto` 输出重审一轮：扫描 32 个文件，改写 26 个文件；`tag_output_review` 已归零。
- pending 真实残留数量从约 190 降到 143，且剩余项更多是尚未 formal 化的科学对象、方法和仪器，而不是泛元信息条目。
- 周报 `推荐论文` 区块的 `标签：` 后已补空格；代码与当前 `2026-04-17 周报.md`/`latest.md` 现有文件都已修正。
