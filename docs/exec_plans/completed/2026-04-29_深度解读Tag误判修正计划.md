# 计划：2026-04-29_深度解读Tag误判修正

## 发现与意外
- `formal_tags.md` 同步到 `focus_tags.json` 时，原解析逻辑会把同级缩进项串成父子链，例如 `指数/IMF/Bx/By`、`指数/IMF/Dst`；本轮已修复为按分类首个 bullet 的缩进作为基准。
- Chen deep_reads cache 原始 tags 没有 FPI/ICON，误加仪器 tag 来自全文推断 alias 子串匹配。
- Chen 既有输出已被 deep-read-only 重写为 `#事件/磁暴 #指数/Dst #指数/Kp`。

## 决策记录
- Chen 文中的 `D index` 按 `指数/Dst` 归一；`K index/Kp ≥ 7` 按 `指数/Kp` 归一。
- `IconSpace`、参考文献标题和拼接 OCR 子串不构成仪器 tag 证据。

## 结果与复盘
- 已新增 `指数/Kp`，并为 `指数/Dst`、`指数/Kp` 补充中文与 OCR 形态映射。
- 已收紧全文推断中的英文缩写 alias 边界，`ofpiezoelectric` 不再触发 FPI，`IconSpace` 不再触发 ICON。
- 已为 FPI/ICON 增加证据保留规则，只有论文实际使用相关仪器/任务数据时才保留。
- 已修复 formal tag 同步解析同级缩进的 bug，并修正指数段正式标签缩进。
- 已重写 Chen 深度解读 tag 行，保留 `#事件/磁暴`、`#指数/Dst`、`#指数/Kp`，移除 `#对象/地磁暴`、`#对象/D指数`、`#对象/K指数`、`#仪器/FPI`、`#仪器/ICON`。
