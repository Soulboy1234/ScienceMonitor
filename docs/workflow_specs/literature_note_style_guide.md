# Literature Note Style Guide

## 目的

这份文档用于固化 `docs/我的文献调研` 中已经形成的真实笔记风格，作为后续文献深度解读、单篇卡片生成和 Obsidian 适配时的首选指导。

## 样本基础

本次归纳基于 `docs/我的文献调研/文件 - 笔记` 下的 170 篇笔记。

- 112 篇以 `----` 起笔，并在文末保留时间戳块
- 167 篇首段直接挂 PDF 或附件链接
- 151 篇已经写成 APA 引用 + DOI 链接
- 170 篇带有「补充信息」
- 169 篇带有「文中引用」
- 102 篇带有「好句子」
- 平均每篇约 5.5 个标签，中位数为 5
- 标签明显偏向层级式写法，最常见外层是 `仪器`、`热层`、`特征`、`模型`、`指数`

这些统计说明，你的笔记不是松散摘录，而是一个已经稳定运行的科研阅读工作流。

这里要额外说明一点：

- 上面的 5.5 / 5 反映的是历史样本分布
- 后续新生成或批量整理时，标签数量执行口径以你给出的《Obsidian标签指南》为准，而不是机械沿用历史平均值

另外，你提供的三份用户自写规范进一步确认并补强了三个点：

- 后续默认应以“成熟稳定版”笔记结构为准
- 标签应采用“闭集优先、具体优先、父子压制”的执行规则
- 新笔记写完后，还要继续完成目录整合，而不是只生成正文

## 核心判断

### 1. 你的主风格不是“模板化摘要”，而是“科研卡片”

最稳定的骨架是：

1. 资源入口
2. 标签
3. APA 引用
4. 你自己的中文判断
5. 后续追踪区

也就是说，笔记的目标不是把论文“解释完整”，而是尽快回答“这篇文章对我有什么用”。

### 2. 写作风格是“高密度、结论优先、允许主观判断”

你的常见特征有：

- 先写核心结论，不先铺背景
- 一句话里同时压入科学问题、数据、方法、机制和结论
- 中英文术语混写，但缩写使用自然，不刻意翻译到底
- 经常把论文结论和自己的已有认知直接对照
- 会明确写出不确定、保留意见或值得继续追踪的问题
- 不是追求完整复述，而是追求研究可用性

典型表达动作包括：

- 直接点出机制判断，例如“可能与……有关”“表明……有贡献”
- 标记和自己结果的关系，例如“我之前的结果是……”“这和前面那篇不完全一致”
- 记录未解决问题，例如“没有定论”“需要进一步分析”“没太懂说实话”
- 顺手埋后续动作，例如 `#Todo`、`#重要`、`#可做`

### 3. 标签风格是“可统计的层级标签 + 少量扁平标签”

你的标签不是平均分布的，而是有明确分工：

- 层级标签负责长期归类
  - 例如 `#热层/密度` `#仪器/CHAMP` `#指数/IMF/By` `#特征/南北半球不对称性`
- 扁平标签负责主题总类、状态或优先级
  - 例如 `#磁暴` `#综述` `#重要` `#Todo` `#空间天气影响`

这说明后续写作时要优先复用既有标签体系，而不是为了形式统一重新造词。

### 4. AI 总结段是可选附层，不是主骨架

少量笔记中出现了 `GPT总结`、`Claude总结`、`Bard总结`、`TXYZ总结` 等段落。这些内容更像辅助阅读痕迹，而不是你的主笔记格式。

后续如果继续保留：

- 必须放在你自己的主结论之后
- 只能作为补充，不应替代首段人工/主总结
- 应显式标记来源，避免与主笔记混在一起

### 5. 历史上有早期版和成熟版，但后续应以成熟版为默认

你的笔记历史上确实存在两种形态：

- 早期/简版：直接开写、无统一收尾、区块名称偶有波动
- 成熟/稳定版：`----` 起笔，资源链接 + 标签，APA，主总结，`「补充信息」`，`「文中引用」`，`「好句子」`，最后带时间戳

后续默认采用成熟版。理由不是“更整齐”，而是它更适合长期维护、批量整理和知识挂接。

### 6. 你的笔记有很强的“挂接意识”

真正像你笔记的深度解读，不应该只总结论文本身，还应主动挂接到：

- 其他文献
- 现象或机制
- 自己已有结果
- 后续可做问题
- 将来写作可复用的表达

这也是为什么 `「补充信息」`、`「文中引用」`、`「好句子」` 都应继续保留。它们不是装饰区块，而是知识挂接层。

## 后续写作时的标准格式

推荐把未来的深度解读统一写成下面这个骨架：

```md
----
- [[PDF文件名.pdf|PDF]] [[Supporting Information.pdf|SI]] #标签1 #标签2 #标签3
- _APA 引用，DOI 必须写成 https://doi.org/..._
- 先用 1-3 句或 1 组短条目，直接写清楚：
  1. 文章回答什么问题；
  2. 用了什么数据、仪器或模型；
  3. 得到了什么最重要的结果；
  4. 你认为真正值得记住的机制、限制或争议点。
- 「补充信息」
    1. 记录值得跟进的问题、和自己工作的联系、方法缺口、潜在选题、反常点。
- 「文中引用」
    1. 记录需要回查的关键前人工作，允许先写占位。
- 「好句子」
    1. 可留空；只有遇到确实值得保留的原句时才摘录。


----
记录时间戳: YYYY-MM-DD HH:mm
```

## 具体写法要求

### 格式

- 优先使用项目符号主导整篇笔记，而不是大段标题分节
- 默认不使用 frontmatter，沿用现有 Obsidian 笔记习惯
- 资源链接放在第一行，确保一眼能回到 PDF 或附件
- 如果当前仓库里没有本地 PDF，可先用 `[DOI](https://doi.org/...)` 或文章网页链接占位，不要伪造失效的 PDF wikilink
- 标签与资源链接同行，维持扫描效率
- 时间戳保留在文末，不放到正文开头
- 如果有关键图，可以用 `![[图片名.png|600]]` 内嵌，但只在图本身值得反复看时才用

### 正文风格

- 先写结论，再补数据和方法
- 优先写“为什么值得记”，不是“论文按什么顺序写”
- 允许使用分号、括号、破折式补充和缩写，保持高信息密度
- 允许保留你的判断痕迹，不要强行改写成完全客观中性的百科语言
- 如果论文有明显缺口、矛盾或你不认可的解释，应直接写出来
- 如果论文和你已有结果相关，应显式写“和我已有结果的关系”

### 标签规则

- 标签数量执行口径默认与《Obsidian标签指南（Codex 执行版）》保持一致：
  - 默认目标：6-8 个
  - 普通研究论文：6-10 个
  - 观测 + 模型论文：6-12 个
  - 综述 / 大综述：6-14 个
  - 一般不要超过 14 个
- 先复用已有高频标签，再考虑新增
- 优先从现有闭集里选，确无必要不要新增
- 优先覆盖四类信息：
  - 科学问题或事件
  - 仪器、数据或模型
  - 关注物理量
  - 关键特征或不对称性
- 具体标签优先于宽标签，例如优先 `#热层/密度` 而不是 `#热层`
- 子标签通常压制父标签，例如已有 `#指数/IMF/By` 时，通常不再保留 `#指数/IMF`
- 标签优先写成名词或名词短语，不写句子
- 新增标签时优先考虑是否能写成层级标签
- 非地球文献额外补 `#其他行星/...`，例如 `#其他行星/火星`、`#其他行星/木星`、`#其他行星/月球`
- `#其他行星/...` 只在论文主体明确是非地球天体时使用；正文里偶然出现 `moon orbit`、`lunar mission`、期刊名里带 `Planetary Science`，都不算充分依据
- `#Todo` `#重要` `#可做` 可以出现在正文中，不必强塞进首行标签串

### 标签输出顺序

后续如果需要输出一行完整标签，默认按下面顺序排列：

1. 研究对象
2. 事件或驱动
3. 指数或控制量
4. 仪器或数据
5. 模型或方法
6. 结果特征
7. 应用或影响
8. 笔记状态

## 推荐的标签思路

优先按下面的顺序想标签：

1. 这篇文章在研究什么现象或问题
   - 例如 `#磁暴` `#磁重联` `#空间天气影响`
2. 它依赖什么仪器、数据或模型
   - 例如 `#仪器/CHAMP` `#仪器/GOLD` `#模型/TIEGCM`
3. 它真正关心的物理量是什么
   - 例如 `#热层/密度` `#热层/风场` `#电离层/TEC`
4. 它最关键的结构、差异或机制是什么
   - 例如 `#特征/南北半球不对称性` `#特征/晨昏不对称性` `#指数/IMF/By`

如果一篇文章跨很多面向，也不要平均铺开。优先保留你后续最可能拿来检索和比较的最关键几个点。

## 深度解读时要保留的“你的动作”

后续生成深度解读时，不能只保留论文信息，还要保留下面这些动作：

- 提炼主问题
- 压缩数据、方法和结果
- 判断最可信的机制或解释
- 标出不确定性、争议和不足
- 连接到你已有工作或未来可做问题
- 补一条值得继续追踪的参考文献或线索

换句话说，未来的“深度解读”应该是你的研究助手笔记，而不是通用论文摘要。

- 归一化时应同时遵守错别字和别名统一，例如 `#Space-X事件 -> #SpaceX事件`、`#电离层/离子飘移 -> #电离层/离子漂移`

## 以后写单篇深读时的执行口径

每次写新笔记时，默认遵循下面这几条：

1. 先给出资源链接、标签和 APA，不写标题党式抬头
2. 主总结必须先落在“问题-数据/方法-结果-我的判断”上
3. 必须保留「补充信息」区，用来记录后续研究价值
4. 标签优先复用已有层级体系，避免临时造词
5. AI 辅助总结只能当附层，不能替代主笔记
6. 打标签时遵守“闭集优先、具体优先、父子压制、保守不脑补”
7. 写完笔记后，如需纳入 Obsidian 系统，应继续完成目录页判断与整合
8. 风格宁可像真实科研卡片，也不要像规整但无用的模板作文
