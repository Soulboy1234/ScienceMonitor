# Literature Codex Quick Guide

仅供 Codex 后续写文献深读、整理 Obsidian 笔记、补目录时快速执行使用。

## 默认目标

写出的内容要像真实科研卡片，而不是模板摘要。

优先回答：

1. 这篇论文对用户有什么用
2. 用了什么关键数据、仪器或模型
3. 最重要的结果、机制、限制是什么
4. 应该打什么标签
5. 应该挂到哪个目录页

## 单篇笔记默认格式

```md
----
- [[PDF文件名.pdf|PDF]] [[Supporting Information.pdf|SI]] #标签1 #标签2 #标签3
- _APA 引用，DOI 必须写成 https://doi.org/..._
- 用 1 段高密度总结，写清：问题、数据/方法、结果、我的判断
- 「补充信息」
    1. 记录后续可做问题、和已有结果的关系、机制缺口、反常点
- 「文中引用」
    1. 记录需要继续追的关键参考文献
- 「好句子」
    1. 默认可留空


----
记录时间戳: YYYY-MM-DD HH:mm
```

## 写作口径

- 先写结论，再补数据和方法
- 保留研究者判断，不写成百科或公文
- 允许直接写“没有定论”“需要继续看”“和我已有结果不一致”
- 不要只复述论文，要主动挂接到已有工作、其他论文、后续问题
- AI 总结段只能当附层，不能替代主总结
- 默认采用成熟稳定版结构，不再回退到历史简版

## 标签规则

- 默认目标：6-8 个
- 普通研究论文：6-10 个
- 观测 + 模型论文：6-12 个
- 综述 / 大综述：6-14 个
- 一般不要超过 14 个
- 这是默认目标和常见范围，不是僵硬硬下限
- 若证据不足，宁可少打，不要乱标

### 标签选择顺序

1. 研究对象
2. 事件 / 驱动
3. 指数 / 控制量
4. 仪器 / 数据
5. 模型 / 方法
6. 结果特征
7. 应用 / 影响
8. 状态标签

### 标签执行原则

- 优先复用既有标签闭集
- 具体标签优先于宽标签
- 子标签通常压制父标签
- 标签服务于检索，不服务于复述全文
- 不要为了凑数量乱加
- `#Todo` `#重要` `#可做` 可放正文，不必都塞首行
- 非地球文献额外补 `#其他行星/...`，例如 `#其他行星/火星`、`#其他行星/木星`

### 常见归一化

- `#Space-X事件` -> `#SpaceX事件`
- `#电离层/离子飘移` -> `#电离层/离子漂移`
- 有 `#指数/IMF/By` / `#指数/IMF/Bz` / `#指数/IMF/Bx` 时，通常去掉 `#指数/IMF`
- 有 `#热层/风场/垂直风` 且全文只谈垂直风时，通常去掉 `#热层/风场`

## 目录整合规则

- `tag` 不是目录，目录也不是 `tag`
- 新笔记整合不能只写正文和标签，还要判断目录入口
- 默认 1 个主目录 + 0-2 个辅助目录
- 优先挂最具体的叶子目录页，不直接挂父目录
- 目录判断看主问题，不看标签镜像
- 目录页更新只做最小必要修改
- 保持原有 wikilink、编号列表和年份顺序
- 输出根目录下 `article_index/` 与 `sub_index/` 的 Obsidian 链接默认保留真实路径，但显示文字只显示页名或笔记名；若文件名末尾带 ` - 重要` 这类状态尾缀，显示别名里应去掉
- 输出侧还要同步 `article_index/index.md` 和 `article_index/sub_index/`
- 新的自动单篇总结和深读默认也要挂入 `sub_index`
- 若没有现成主题页，允许新建 `sub_index/<主题>.md`，并把它加入 `index.md`
- 非地球文献优先进入 `6 - 其他行星` 下对应星球的叶子页；若还有明确交叉主题，再补 `7 - 太阳与日球层`、`8 - 波粒相互作用`、`9 - 高能粒子与辐射带` 等辅助页
- `1-4` 号地球主体目录默认不保留非地球文献条目
- 对输出根目录下的 `manual/` 默认只修正文内可确认的 Obsidian 链接，不改正文内容
  分类确有需要时，只允许对首行标签串做最小修正，例如补或去掉 `#其他行星/...`

## 每次完成前检查

1. 文件名是否还是 `作者 年份 - 期刊 - 中文功能性概括`
2. 首行是否有资源链接和标签
3. APA 和 DOI 是否规范
4. 主总结是否写到了“问题-数据/方法-结果-我的判断”
5. 是否保留了「补充信息」「文中引用」「好句子」
6. 标签是否遵守闭集优先、具体优先、父子压制
7. 是否已经判断主目录和辅助目录
8. 修改目录页时是否保持最小修改原则
9. 是否已经同步输出根目录下的 `article_index/`，并确认新增笔记能从 `sub_index` 找回
