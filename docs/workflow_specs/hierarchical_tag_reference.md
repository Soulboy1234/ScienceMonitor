# Hierarchical Tag Reference

## 目的

这份文件用于给单篇总结、深度解读和批量整理任务提供一个可直接查阅的分级标签参考表。

它解决的是：

- 常用标签一般长什么样
- 分级标签优先怎么命名
- 标签数量、顺序和冲突消解通常怎么处理

## 当前定位

这份文件是人工阅读参考，不是运行时 source of truth。

当前分工是：

- 运行时标签归一化与同义词映射：`config/focus_tags.json`
- 运行时标签执行逻辑：`src/sciencemonitor/tags.py`
- 标签写作风格与人工审阅参考：本文件

因此：

- 机器要用的 canonical 名称、别名映射、开放词表约束，改 `config/focus_tags.json`
- 人要快速查看“常用标签如何组织、如何取舍”，看本文件

## 使用原则

- 优先从这份清单里选
- 具体标签优先于宽标签
- 子标签通常压制父标签
- 允许保守少打，不允许随意乱造

## 数量与顺序建议

### 标签数量

默认执行口径与标签写作风格保持一致：

- 默认目标：6-8 个
- 普通研究论文：6-10 个
- 观测 + 模型论文：6-12 个
- 综述 / 大综述：6-14 个
- 一般不要超过 14 个

说明：

- 这里是默认目标和常见范围，不是僵硬硬下限
- 若正文证据不足，宁可保守少打，也不要为了凑数量乱标

### 推荐输出顺序

完整标签行默认按这个顺序排列：

1. 研究对象
2. 事件 / 驱动
3. 指数 / 控制量
4. 仪器 / 数据
5. 模型 / 方法
6. 结果特征
7. 应用 / 影响
8. 状态标签

## 归一化与冲突消解

### 别名统一

- `#Space-X事件` 统一为 `#SpaceX事件`
- `#电离层/离子飘移` 统一为 `#电离层/离子漂移`

### 父子压制

- 有 `#指数/IMF/By` 时，通常删除 `#指数/IMF`
- 有 `#指数/IMF/Bz` 时，通常删除 `#指数/IMF`
- 有 `#指数/IMF/Bx` 时，通常删除 `#指数/IMF`
- 有 `#热层/风场/垂直风` 且全文只讨论垂直风时，通常删除 `#热层/风场`
- 有 `#模型/MSIS/修正` 且全文只讨论修正版本时，可删除 `#模型/MSIS`

### 近义表达优先映射

- “南北半球不对称 / hemispheric asymmetry” → `#特征/南北半球不对称性`
- “昼夜不对称 / day-night asymmetry” → `#特征/昼夜不对称性`
- “晨昏不对称 / dawn-dusk asymmetry” → `#特征/晨昏不对称性`
- “经度分布 / longitude dependence” → `#特征/经度结构`
- “季节依赖 / seasonal variation” → `#特征/季节变化`
- “中小尺度波动 / mesoscale disturbance” → `#特征/中小尺度扰动`

## 使用提醒

- 每篇至少保留 1 个对象标签
- 事件标签常规 0-1 个，必要时 1-2 个
- 仪器标签常规 1-3 个，只保留关键证据来源
- 特征标签常规 1-2 个，最多 3 个
- 状态标签是辅助层，不能淹没主题标签
