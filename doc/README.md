# ScienceMonitor Docs

这个目录现在按“是否真正控制程序/agent 行为”分成三层：

- [runtime_control](runtime_control)
  - 真正会被程序读取并影响 LLM 提示词或调研偏好的文档
- [harness_control](harness_control)
  - 主要控制 agent/harness 的写作风格、模板、标签和工程规范
- [user_guides](user_guides)
  - 主要给用户阅读、了解部署和设计思路的说明文档
