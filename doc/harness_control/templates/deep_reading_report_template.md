# Deep Reading Report Template

这份模板同时适用于：

- `my_work/papers/` 下的人工深读
- `auto/deep_reads/` 下的自动深读

目标不是写成“长篇论文综述”，而是写成：

> **和单篇总结风格统一、适配 Obsidian、又真正体现深度阅读判断力的科研卡片。**

---

```md
# 论文深度阅读报告
----
- [[PDF文件名.pdf|PDF]] [[Supporting Information.pdf|SI]] [[auto/article_summaries/对应单篇总结|单篇总结]] [[research_reports/YYYY-MM-DD 周报|对应周报]] #标签1 #标签2 #标签3 #标签4 #标签5 #标签6
- _APA 引用，DOI 必须写成 https://doi.org/..._

## 论文信息
- **题目**：
- **作者**：
- **期刊**：
- **年份**：
- **论文类型**：

### 一句话总述
这篇文章针对什么科学问题，使用了什么数据，采用了什么方法，得到了什么结果。这里不是简单复述摘要，而是先给出一个压缩后的核心判断。
这一段至少要回答三个问题：
1. 这篇文章最重要的贡献是什么；
2. 最有力的证据是什么；
3. 最值得保留的判断与结论是什么。
写作要求：
- 直接写“这篇文章针对……”“这篇文章关注……”或“作者研究的是……”
- 不要用“不是……而是……”这类对比式开头
- 除专有名词、仪器名、模型名、指数名和变量名外，尽量使用中文表达

## 论文详解
### 1. 为什么做这项研究
压缩成 1-2 段，说明作者真正瞄准的科学问题。
这一部分重点写：
- 科研背景是什么；
- 已有认识推进到了哪里；
- 为什么还需要做这篇工作；
- 这个问题对空间物理、你的研究方向或应用问题有什么价值。
不要只抄标题，要把问题拆成 2-4 层递进关系。

### 2. 作者是怎么推进这个问题的
只写关键数据、关键方法和关键比较框架，不按论文章节流水账展开。
这一部分重点回答：
- 用了什么数据、仪器、样本、事件和时间窗；
- 作者如何把问题一步步推进到结论；
- 作者拿什么做对照、做剥离、做验证；
- 结论靠什么支撑，不一定是统计显著性，也可能是物理一致性；
- 数据和方法本身是否站得住，还存在哪些问题。

### 3. 文章最关键的结果是什么
只保留真正要记住的 2-4 点。
这一部分要明确区分：
- 最硬的结论是什么；
- 哪些是次级结论；
- 哪些更像合理解释或外推，还需要保留。
建议至少包括：
- 1 条核心主张
- 2-3 条次要或外推结论

### 4. 这篇文章的新意以及对科学研究的贡献
说明它相对已有工作到底往前推进了一步什么。
不要泛泛写“很新”，而要指出：
- 新在问题定义；
- 新在数据或方法；
- 新在证据链；
- 还是新在对已有认识的修正。
同时要评价：
- 它在已有研究链条里补上的具体位置；
- 文章的价值；
- 文章当前的可信度大概处在什么水平。

### 5. 文章的局限性
这里要集中写三类内容：
- 作者已经说明的局限；
- 作者没有充分展开但你认为存在的局限；
- 文章成立所依赖的隐含假设。

### 6. 文章的可复现性
这里要评价：
- 是否能根据文中信息复现主要分析；
- 难点在哪里；
- 这些难点是否能够克服；
- 如果不能完全复现，最可能卡在哪些关键环节。

### 7. 与已有工作的关系
说明它和前人工作、和你自己的工作分别是什么关系。
这一部分重点回答：
- 对你的主题有什么启发；
- 哪些结果值得后续继续跟；
- 哪些地方不宜直接拿来当定论；
- 和你已有工作是互补、推进、修正还是冲突关系。

## 总结
### 最终结论
用 1 段收束全文，回答：
- 这篇文章最值得记住的是什么；
- 最不该被过度解读的是什么；
- 它在你的知识库里应该处在什么位置。

### 补充信息与挂接
- 和我已有工作的关系：
- 后续值得追踪的问题：
- 需要人工复核的点：
- 已挂接的目录：

----
记录时间戳: YYYY-MM-DD HH:mm
```

## 结构逻辑

这套模板的主逻辑是：

1. 先用“文件链接 + 标签 + APA”完成科研卡片入口
2. 再用“一句话总述”先给出压缩判断
3. 接着进入“论文详解”，按 `问题 -> 方法 -> 结果 -> 贡献 -> 局限 -> 可复现性 -> 与已有工作的关系` 的顺序展开
4. 最后用“总结 + 补充信息与挂接”收束，方便进入你的知识库体系

## 执行原则

1. `my_work/papers/` 和 `auto/deep_reads/` 尽量都用这套结构。
2. 正式报告开头不单列“标签（Tags）”“目录归档建议”“证据范围”这些章节。
3. 标签直接放在第一行链接后，风格向 `article_summaries` 靠拢。
4. 如果证据不完整，可以在正文中自然交代证据边界，但不要让它占据开头主要版面。
5. APA 引用必须保留，DOI 必须写成网址。
6. 允许篇幅长，但每一节都必须有判断，不写空泛套话。
7. 统一结构优先，但正文要保留“深读感”和研究判断力，而不是写成模板作文。

## 文件命名

深度解读文件名本身不写进正文，命名规则单独执行：

- `作者姓 (年份) - 期刊缩写 - 文章内容简单总结深度解读.md`
- 如果已有 `article_summaries` 的单篇总结，内容总结尽量与单篇总结一致，再加 `深度解读`
