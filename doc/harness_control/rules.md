# Rules

## 不要轻易改的核心主张

- 监控范围面向整个空间物理，不只限于单一子方向
- 抓取准确性优先于花哨功能
- 单篇总结模板必须保持科研笔记风格
- 标签必须简洁、可统计、适配 Obsidian
- `tag` 与目录是并列检索系统，新笔记整合不能只更新其中一个
- 目录页更新遵循最小修改原则，优先维护叶子目录
- 输出根目录下的 `article_index/` 是输出侧索引入口，新生成的单篇总结和深读默认也要同步到 `sub_index`
- 输出根目录下的 `manual/` 默认只修正当前 vault 内可以确认的链接，不改正文内容
- 引用统一使用 APA，DOI 用网址形式
- 输出目录、日志目录、文档目录严格分开
- LLM 层必须可以被关闭，也必须可以替换为其他 API

## 修改逻辑前要先确认的点

- 会不会影响已有标签统计
- 会不会让文件名或目录结构再次混乱
- 会不会降低抓取可审计性
- 会不会让用户无法脱离 Codex 环境运行
