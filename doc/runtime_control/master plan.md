# Master Plan

## 为什么要做

Space Physics 相关文献分散在多个期刊，更新频繁，人工逐刊查看容易漏掉新文章，也不利于长期积累研究线索。这个项目的目标，是把“每天看期刊目录、筛文章、写摘要、判断趋势”这件事情自动化。

## 项目意义

- 降低日常检索成本
- 提高跨期刊追踪能力
- 更快发现新事件、新方法、新仪器和新数据
- 为后续做周报、月报和专题趋势分析打基础
- 为个人研究和团队知识库持续沉淀结构化材料

## 最终希望达到的状态

- 每天自动抓取主要空间物理期刊的新文章
- 自动生成可读的日报或周报
- 自动生成可复用的单篇文献卡片
- 在规则法和 LLM 分析之间自由切换
- 让输出天然适合 Obsidian 继续整理和积累

## 当前用户研究重心

用户的历史工作主线覆盖电离层、热层、日地耦合、漠河热层风、多仪器联合观测、磁暴过程诊断，以及基于深度学习的热层质量密度建模。

在当前阶段，用户的研究兴趣和后续工作布局正在发生变化，后续需要在文献调研和报告生成时给予更高优先级的方向包括：

- 热层密度及其变化机制
- 空间环境对卫星运行、轨道衰减、阻力环境和任务安全的影响
- 空间天气对人类生产生活的影响
- 与应用相关的空间环境风险评估、预报和响应
- 热层风相关研究，但不再局限于漠河区域

这意味着系统后续在做文献筛选、重点推荐和“值得特别关注”提示时，需要逐步从“漠河和区域观测主线”扩展到“更广义的热层密度、卫星影响和应用影响主线”。

## 文献调研中的特别提醒策略

后续在自动文献调研时，遇到以下主题应优先提醒用户，即便它们不完全落在用户过去最核心的台站或区域工作中：

- 热层质量密度异常、长期变化、建模和数据同化
- 磁暴、亚暴、行星际环境变化对卫星阻力和轨道环境的影响
- 空间天气导致的卫星故障、通信导航受扰、轨道维持压力增加等应用问题
- 空间环境对低轨卫星星座、姿轨控和任务规划的影响
- 面向业务化或准业务化的预报模型、经验模型、机器学习模型
- 热层风与热层密度、卫星阻力、能量沉降之间的耦合关系

如果出现以下类型的文章，即使不在漠河、东亚扇区或传统电离层主题内，也应提高优先级：

- 直接讨论 TMD、satellite drag、orbit decay、thermospheric forcing 的文章
- 讨论 space weather societal impacts、operational impacts、infrastructure impacts 的文章
- 讨论上游空间环境信息如何改善卫星环境建模和预报的文章

## 这是一个可持续更新的偏好区

这一部分不是固定不变的说明，而是项目后续需要长期维护的“用户研究偏好”记录。今后如果用户的关注重点继续变化，应优先在这里更新，再同步影响周报、单篇卡片和重点提醒逻辑。
