# Implementation Plan

## 阶段 1：监控源建设

- 建立期刊注册表
- 按期刊配置 ISSN、抓取模式、优先级和日期字段
- 对核心期刊做精确源审计

## 阶段 2：数据抓取与标准化

- 从 Crossref 抓取近期文章
- 必要时补抓 DOI 落地页摘要
- 统一作者、DOI、发布日期和期刊名格式
- 做去重和落库

## 阶段 3：分析层建设

- 规则法主题分类
- 规则法标签生成
- LLM 单篇总结
- LLM 周报摘要
- 支持本地 Codex 和外部 API

## 阶段 4：输出层建设

- 周报模板
- 单篇文献模板
- 审计表
- Obsidian 友好的标签和文件名

## 阶段 5：运维与迭代

- 定时运行
- 抓取失败记录
- 源审计日志归档
- 基于用户反馈持续收紧标签和主题分类
